# 📋 Daily Check-in - Complete Guide

## 🎯 **What is Daily Check-in?**

Daily check-in is a 7-day reward cycle where you can earn PNRP every day by watching one ad.

**Rewards:**
- Day 1: 5 PNRP
- Day 2: 10 PNRP
- Day 3: 15 PNRP
- Day 4: 20 PNRP
- Day 5: 25 PNRP
- Day 6: 30 PNRP
- Day 7: 50 PNRP

**Total in 7 days: 155 PNRP!** 🎉

---

## ✅ **How to Claim:**

### **Step 1: Open Daily Check-in**
```
Dashboard → Click "Daily Check-in" card (Yellow card)
```

### **Step 2: Check Your Day**
```
Modal will show:
- Current day (1-7)
- Today's reward amount
- 7-day progress bar
```

### **Step 3: Watch Ad**
```
- Click "Watch Ad & Claim" button
- Wait 5 seconds (ad simulation)
- Ad will auto-claim after 5 seconds
```

### **Step 4: Confirmation**
```
Success alert will show:
✅ Daily Check-in Success!
🎁 Reward: +X PNRP
💰 New Balance: X PNRP
📅 Day X/7
```

### **Step 5: Verify**
```
- Page will auto-reload
- Check header balance
- Or go to Wallet → Transaction History
```

## 🔍 **How to Verify Reward Was Claimed:**

### **Method 1: Check Wallet**
```
1. Go to Wallet page
2. Look at Transaction History
3. Find "Daily check-in Day X" transaction
4. Should show +X PNRP
```

### **Method 2: Check Balance**
```
1. Note your balance before claim
2. After claim, check header balance
3. Should increase by reward amount
4. If not showing, hard refresh (Ctrl+Shift+R)
```

### **Method 3: Try Claiming Again**
```
1. Open Daily Check-in modal
2. If shows "Already checked in" → You claimed! ✅
3. If shows "Watch Ad" button → Not claimed yet
```

## 🕐 **Timing & Rules:**

### **When can I claim?**
- Once every 24 hours
- Resets at midnight UTC
- Check modal for "Next claim available in X hours"

### **What if I miss a day?**
- Streak resets to Day 1
- You don't lose previous rewards
- Just start over from Day 1

### **Can I claim multiple times per day?**
- No, only once per 24 hours
- If you try again, you'll see "Already checked in"

### **Do I need to claim at exact same time?**
- No! Anytime in the 24-hour period
- Resets at midnight UTC

## 💡 **Common Issues & Solutions:**

### **Issue 1: "Already checked in" but I didn't claim**

**Reason:**
- You DID claim earlier today
- You may have forgotten
- Or claimed and didn't notice

**Solution:**
```
1. Check Wallet transaction history
2. Look for today's date
3. If transaction exists → You claimed ✅
4. If no transaction → Contact admin
```

### **Issue 2: Reward claimed but balance not updated**

**Reason:**
- Browser cache showing old balance
- React state not refreshed

**Solution:**
```
1. Hard refresh (Ctrl + Shift + R)
2. Check Wallet page directly
3. Check transaction history
4. Reward IS in database ✅
```

### **Issue 3: Can't open check-in modal**

**Solution:**
```
1. Refresh page
2. Clear browser cache
3. Try different browser
4. Check if services are running
```

### **Issue 4: Ad not playing**

**Note:**
- Ads are simulated (5-second wait)
- No real video plays
- Just click "Watch Ad" and wait

**If stuck:**
```
1. Wait full 5 seconds
2. Don't close modal
3. Don't click multiple times
4. If nothing happens → Refresh and try again
```
